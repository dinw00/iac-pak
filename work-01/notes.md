# Практика 1. Журнал ручных действий (вариант 05)

Машина pak-05-web-manual, созданная мышкой в веб-консоли Яндекс Облака.

## Создание машины в веб-консоли

1. Открыть https://console.yandex.cloud и войти аккаунтом Яндекса.
2. Выбрать каталог default.
3. Перейти в Compute Cloud → Виртуальные машины.
4. Нажать «Создать виртуальную машину».
5. Ввести имя pak-05-web-manual.
6. Нажать «Добавить метку» и задать created-by = console.
7. Выбрать образ загрузочного диска Ubuntu 24.04.
8. Выбрать зону доступности ru-central1-b.
9. Переключить тип диска на HDD.
10. Задать размер диска 20 ГБ.
11. Открыть вкладку «Своя конфигурация».
12. Выбрать платформу Intel Ice Lake.
13. Задать vCPU = 2.
14. Задать гарантированную долю vCPU 20 %.
15. Задать RAM = 2 ГБ.
16. Отметить «Прерываемая».
17. Оставить подсеть default-ru-central1-b.
18. Публичный IP-адрес — «Автоматически».
19. Способ доступа — SSH-ключ, логин student.
20. Нажать «Добавить ключ», вставить id_ed25519.pub, имя ключа pak-05-wsl.
21. Выключить «Резервное копирование».
22. Нажать «Создать ВМ» и дождаться статуса Running.

## Настройка веб-сервера на машине

23. Скопировать публичный IP-адрес машины из консоли.
24. Подключиться по SSH: ssh student@<IP>, на вопрос об отпечатке ответить yes.
25. Обновить список пакетов: sudo apt update.
26. Установить nginx: sudo apt install -y nginx.
27. Проверить службу: systemctl status nginx (active (running)).
28. Открыть http://<IP> в браузере — стартовая страница nginx.
29. Выключить разбор истории: set +H.
30. Заменить заголовок страницы на «vmlab on $(hostname)» командой sed.
31. Обновить страницу в браузере — «vmlab on pak-05-web-manual».
32. Выйти с машины: exit.

Итого: создание машины в веб-консоли — 22 действия (п. 1–22),
вместе с настройкой веб-сервера — 32 действия.
